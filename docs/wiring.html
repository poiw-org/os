Notes

Colours. Each colour keeps the job it had on the legacy sheet. Only the pin at the board end changes: move it to the GPIO in the table.

Idle LED is back. The legacy sheet merged Idle into Busy. The firmware drives a separate Idle LED on GPIO27 (on when online, blinking when offline). Pick any free colour and write it here: ________

Relay on GPIO25. D0 moved to D5 because it went HIGH at boot and opened the lock. GPIO25 is not a strapping pin, so the lock stays shut on boot. Never use GPIO 0, 2, 5, 12 or 15 for the relay.

GND wire. The legacy legend has the light blue G line crossed out. Check which wire carries ground before re-soldering. All grounds (ESP32, PN532, relay DC−, LEDs, buzzer, L7805) must be common.

Exit switch. The legacy sheet ties the push switch into the relay input line. ESP32 GPIOs are 3.3V only: pressing the switch must never put 5V onto GPIO25.

PN532. Runs in I2C mode on 3V3. Change the pins with NFC_SDA / NFC_SCL in config.h.
