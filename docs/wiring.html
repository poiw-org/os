Notes

Colours. Each legacy colour keeps its job; only the pin at the board end changes. Write the colours of the new wires in the blanks.

BLE bridge. UART2 crosses over: door TX (GPIO17) → bridge RX (GPIO20), bridge TX (GPIO21) → door RX (GPIO16). Share ground and the 5V rail. Super Mini clones differ: check the board's pinout before soldering.

Bridge reset (optional). BRIDGE_RESET is not set in config.h. To let the door restart a silent bridge, wire a free GPIO to the bridge's EN pad and define it. GPIO27 is taken by RESET_PIN.

RGB LED. The three status LEDs are now one common-cathode RGB LED, driven HIGH = on with PWM. There is no separate Idle LED.

Relay on GPIO25. Not a strapping pin, so the lock stays shut on boot. Never use GPIO 0, 2, 5, 12 or 15 for the relay.

Exit switch. The legacy sheet ties it into the relay input line. ESP32 GPIOs are 3.3V only: the switch must never put 5V onto GPIO25.
